Setting the remote project folder

Now we instruct gPLINK that we are running in remote mode, by checking the Link to a remote project box once we have selected the local folder. gPLINK uses the SSH protocol to connect to any server that provides this service. Enter the hostname and your username here. You probably want to leave the port number set to the default, 22.
