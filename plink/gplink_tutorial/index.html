PLINK: Whole genome data analysis toolset

A brief tour of gPLINK, PLINK and Haploview

These pages provide a brief introduction to how gPLINK, PLINK and Haploview interact.

They do not provide a great deal of detail of actual analysis -- the focus is mainly on how to configure gPLINK.

gPLINK can run in two modes -- either locally or remotely. In this tour we focus on running gPLINK in remote mode (i.e. with gPLINK and Haploview on the local machine, e.g. a Windows laptop, but PLINK, the data and all computation residing on a remote Linux/Unix server).
